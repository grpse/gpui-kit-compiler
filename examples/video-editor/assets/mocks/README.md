# Visual reference fixtures

`project.json` holds the original fictitious media catalog, folders, processing percentages, track names, and clip ranges. The supplied screenshots remain here as the source of fixture thumbnails. Start the application with `--mock` to inspect this reference project. Normal startup imports the real files from `../media` and never inserts this fixture catalog or processing queue.

Effects, tracking, sharing, and project export controls remain interface prototypes and identify their actions as mocked. Real media import, separate channel tracks, native video decoding, timeline audio output, mute/gain, linked split/delete, seeking, and looping are implemented.
